LOVIE SURPRISE WEBSITE

Open index.html to preview it.

To put it online for free with GitHub Pages:
1. Create a new GitHub repository (for example: lovie-surprise).
2. Upload index.html and the entire photos folder.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. GitHub will give you the public website address. You can turn that address into a QR code.

MUSIC NOTE:
The site is themed around “Fly Me to the Moon,” but the copyrighted recording is not bundled. If you own/have permission to use an audio file, it can be added later.
